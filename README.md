# UniRule

An AI-powered question-answering system over a university rulebook corpus.

## Phase 1 Scaffolding

This project scaffolding contains:
- `/app`: FastAPI backend structure.
- `/data`: Synthetic corpus and contradiction registry.
- `/storage`: Embeddings vector files.
- `/scripts`: Data generation and ingestion.
- `/tests`: Evaluation and testing.
- `/frontend`: Vanilla JS frontend.
